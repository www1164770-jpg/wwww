### Expected recommendation regression contract

`npm run test:career-switching` permanently checks the data-flow invariant:

```text
recommendation API 60 items -> current career Top 48 -> batch 16
-> refresh batch 16 -> career switch has visible items
```

It also statically requires `visibleCareerSites` to declare `careerCode` from
`activeCareerCode` before constructing its batch metadata, so the original
unscoped-variable `ReferenceError` cannot silently return through that path.
Browser acceptance additionally treats console `ReferenceError` as a failure.
