# 前端本地验收清单

1. 启动后端服务，确认接口地址与本地前端配置一致。
2. 启动前端服务。
3. 打开首页，确认首页内容、加载态、错误态和搜索入口正常。
4. 注册一个新账号。
5. 使用注册账号登录。
6. 首次登录后进入问卷页面。
7. 提交职业问卷，确认保存成功并跳转回首页。
8. 首页查看推荐资源，确认推荐理由正常展示；无推荐数据时热门资源兜底。
9. 打开分类导航，确认一级分类列表、搜索和空态正常。
10. 进入分类详情。
11. 使用分类、标签、免费/付费、地区和排序筛选条件。
12. 搜索网站，分别验证空关键词和有关键词搜索。
13. 进入网站详情页，确认简介、详细介绍、标签、适用职业、评论和相似网站区域正常。
14. 收藏网站，确认按钮状态和“已收藏”提示即时更新。
15. 进入“我的收藏”。
16. 取消收藏，确认该项从当前列表移除并显示“已取消收藏”提示。
17. 进入个人中心，确认“我的收藏”入口、问卷摘要和推荐入口正常。
18. 管理员登录后台，确认普通用户不能访问后台。
19. 新增网站，确认名称和 URL 校验、保存状态和保存成功后列表刷新。
20. 编辑网站，确认保存成功后列表刷新。
21. 删除网站，确认二次确认和删除成功提示。
22. 新增分类，确认一级/二级分类保存和列表刷新。
23. 新增标签，确认标签类型、使用次数展示和列表刷新。
24. 查看用户列表，确认用户状态、问卷状态和禁用/解禁操作正常。
25. 审核评论，确认通过、驳回、删除操作成功后列表刷新。
