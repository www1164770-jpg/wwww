# 前端本地验收清单

1. 启动后端服务，确认接口地址与本地前端配置一致。
2. 启动前端服务。
3. 打开首页，确认首页内容、加载态、错误态和搜索入口正常。
4. 注册一个新账号。
5. 使用注册账号登录。
6. 首次登录后进入问卷页面。
7. 提交问卷，确认保存成功并跳转到后续页面。
8. 回到首页查看推荐资源。
9. 进入分类页，确认分类列表、筛选和空态正常。
10. 搜索网站，分别验证空关键词和有关键词搜索。
11. 查看网站详情，确认简介、标签、适用职业、评论和相似网站区域正常。
12. 收藏网站，确认按钮状态和提示即时更新。
13. 进入“我的收藏”。
14. 取消收藏，确认该项从当前列表移除。
15. 进入个人中心，确认问卷摘要、推荐入口、收藏入口和密码表单正常。
16. 管理员账号进入后台。
17. 新增网站，确认基础校验、保存状态和保存成功后列表刷新。
18. 编辑网站，确认保存成功后列表刷新。
19. 删除网站，确认二次确认和删除成功提示。
20. 管理分类和标签，确认新增、编辑、删除、空态和错误态正常。
21. 查看用户管理和评论审核，确认禁用 / 解禁、审核按钮、加载态和空态正常。
